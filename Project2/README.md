# Project2 빌드 안내

## 다른 컴퓨터에서 열기

1. Visual Studio Installer에서 **C++를 사용한 데스크톱 개발** 워크로드를 설치합니다. 이 프로젝트는 `v145` 도구 집합을 사용하므로 이를 지원하는 Visual Studio와 Windows SDK가 필요합니다.
2. Installer의 개별 구성 요소에서 **vcpkg 패키지 관리자**가 설치되어 있는지 확인합니다.
3. GitHub Desktop으로 저장소를 Clone 또는 Pull합니다.
4. `Project2.slnx`를 열고 **Debug / x64**로 빌드합니다. 최초 빌드에는 인터넷 연결이 필요합니다.

프로젝트가 `vcpkg.json`을 읽어 GLEW, GLFW, GLM을 자동 설치하고 포함 경로와 링크 설정을 적용합니다. 컴퓨터별 절대 경로를 추가할 필요는 없습니다.

## GLM 사용

```cpp
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>
#include <glm/gtc/type_ptr.hpp>
```

의존성 버전 기준은 `vcpkg.json`의 `builtin-baseline`으로 고정합니다. GitHub Desktop으로 의존성 변경을 공유할 때는 **vcpkg.json을 커밋**하세요. 자동 생성되는 `vcpkg_installed`와 빌드 결과는 `.gitignore`에 따라 제외합니다.

빌드 이후에도 편집기에 헤더 오류가 남으면 프로젝트를 다시 로드하거나 Visual Studio를 다시 열어 보세요.

## 실습 파일 선택

현재 Debug/x64 구성은 `1-23.cpp`를 빌드합니다. 여섯 면으로 된 무대 안에서 로봇이 걷고, 장애물을 만나면 돌아서며, 점프로 장애물에 오르내립니다. `vertex7.glsl`·`fragment7.glsl` 셰이더와 VAO/VBO를 사용합니다. 다른 실습 파일을 실행하려면 해당 파일을 프로젝트에 추가하고, `main()`이 있는 기존 실습 파일은 **빌드에서 제외**하세요. 한 실행 프로그램에는 `main()`이 하나만 있어야 합니다.

`1-18.cpp`는 `1-17.cpp`의 OBJ 읽기, 셰이더, VAO/VBO 구성을 재사용하며, `cube.obj`에 들어 있는 구로 중심 구, 행성 3개, 달 3개를 그리는 실습입니다. OBJ와 셰이더 파일은 빌드 후 실행 파일 폴더에도 복사됩니다.

`1-17.cpp`의 OBJ 읽기 함수는 `l` 선분도 읽습니다. `g x`, `g y`, `g z` 그룹의 선은 각각 빨강, 초록, 파랑으로 저장됩니다. `1-16.cpp`처럼 모든 도형과 축을 하나의 `vertices`, VBO, VAO에 저장하며, OBJ에 나온 면과 선의 순서를 유지합니다. 기본 `cube.obj`에는 축, 큐브, 원뿔, 구 순서로 데이터가 들어 있습니다. `glDrawArrays`에 지정할 시작 위치/정점 개수는 축 `0/6`, 큐브 `6/36`, 원뿔 `42/192`, 구 `234/2880`입니다.

## 실습 18 조작

| 키 | 동작 |
| --- | --- |
| `p` / `Shift+P` | 직각 투영 / 원근 투영 |
| `m` / `Shift+M` | 솔리드 모델 / 와이어 모델 |
| `w`, `a`, `s`, `d` | 전체 도형을 위, 왼쪽, 아래, 오른쪽으로 이동 |
| `+`, `-` | 전체 도형을 z축 양/음 방향으로 이동 (숫자 키패드도 지원) |
| `1` | 모든 행성과 달 궤도의 반지름을 함께 확대 / 축소 |
| `2` | 중심 구의 크기·색상 애니메이션 시작 / 정지 |
| `3` | 달 궤도의 z축 회전 시작 / 정지 |
| `q` | 종료 |

세 행성의 궤도는 xz 평면 및 이를 z축으로 ±45도 기울인 평면에 있고, 각각 다른 속도로 공전합니다. 달은 각 행성을 따라 이동하면서 화면에 평행한 타원 궤도로 공전합니다. `1`은 궤도 반지름 배율을 1.0배와 1.3배 사이에서 부드럽게 바꿉니다. `2`, `3`을 끄면 중심 구의 크기·색상과 달 궤도의 회전 각도는 현재 상태를 유지합니다.

## 실습 23 조작

| 키 | 동작 |
| --- | --- |
| `o` | 앞벽을 위쪽으로 축소하며 열기 / 닫기 |
| `w`, `a`, `s`, `d` | 로봇의 이동 방향 변경: 앞(-Z), 왼쪽(-X), 뒤(+Z), 오른쪽(+X) |
| `+`, `-` | 걷기 속도와 팔다리의 흔들림 크기·속도 조절 (`=`, 숫자 키패드도 지원) |
| `j` | 평지에서는 제자리 점프, 장애물 가까이에서는 뛰어오르기, 장애물 위에서는 빈 바닥으로 뛰어내리기 |
| `i` | 로봇·점프·속도·앞벽·카메라를 초기 상태로 되돌리기 |
| `z` / `Shift+Z` | 카메라를 앞으로 / 뒤로 이동 |
| `x` / `Shift+X` | 화면을 기준으로 카메라를 왼쪽 / 오른쪽으로 이동 |
| `y` / `Shift+Y` | 현재 화면 중심을 기준으로 양 / 음 방향 공전. 같은 키를 다시 누르면 현재 위치에서 정지 |
| 화살표 위 / 아래 | 카메라를 앞으로 / 뒤로 이동 |
| 화살표 왼쪽 / 오른쪽 | 카메라를 화면의 왼쪽 / 오른쪽으로 이동 |

무대는 가로 5, 높이 3, 깊이 3이며 바닥 중점은 `(0, 0, 0)`입니다. 크기가 다른 장애물 세 개는 실행할 때 서로 겹치지 않는 무작위 위치에 생성됩니다. `i`를 누르면 같은 장애물 배치에서 다시 시작합니다. 무대에는 앞면 컬링, 장애물과 로봇에는 뒷면 컬링을 적용합니다. 앞벽의 윤곽선을 함께 표시해 카메라 쪽 면이 컬링된 상태에서도 개폐 움직임을 확인할 수 있습니다.
