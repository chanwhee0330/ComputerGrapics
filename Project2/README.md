# Project2: Visual Studio에서 수정하고 실행하기

1. ZIP 전체를 압축 해제합니다.
2. Visual Studio에서 **Project2.sln**을 엽니다. 처음 실행되는 프로젝트는 `Project2`입니다.
3. **Debug / x64**를 선택하고 코드를 수정한 뒤 **Ctrl+F5**로 빌드하고 실행합니다.

Visual Studio의 **C++를 사용한 데스크톱 개발** 워크로드와 Windows SDK는 설치되어 있어야 합니다.
이 ZIP은 Visual Studio 자체를 설치하는 파일이 아닙니다.

## 경로와 라이브러리 설정

- GLEW, GLFW, GLM과 x64/Win32용 라이브러리가 `dependencies`에 포함되어 있습니다.
- `GraphicsCommon.props`가 상대 경로로 헤더 / 링크 경로를 설정합니다. 직접 경로를 입력할 필요가 없습니다.
- vcpkg 설치나 첫 빌드 시 인터넷 연결이 필요하지 않습니다.
- 특정 `v145` 도구 집합을 강제하지 않고 해당 Visual Studio의 기본 C++ 도구 집합을 사용합니다.
- Windows SDK는 해당 컴퓨터에 설치된 버전을 선택하도록 `10.0`으로 지정합니다.
- 셰이더, OBJ, DLL은 각 실행 파일 폴더로 자동 복사됩니다.
- Debug/Release와 x64/x86 모두에 별도의 출력 경로를 사용합니다.

## 다른 실습 실행하기

솔루션 탐색기의 **실습별 실행** 폴더를 펼치고 원하는 실습 프로젝트를 마우스 오른쪽 버튼으로 눌러
**시작 프로젝트로 설정**한 다음 **Ctrl+F5**를 누릅니다.
프로젝트마다 소스 파일 하나만 빌드하므로 `main()` 중복 링크 오류가 나지 않습니다.
`basiccode_ver2.cpp`에 적어 둔 참고 주석도 그대로 포함되어 있습니다.

원본 `Project2` 프로젝트는 현재 선택한 소스 하나를 빌드합니다. 다른 실습은 **실습별 실행** 폴더에서 선택하면 편합니다.
코드 수정은 `Project2` 폴더 안의 기존 `.cpp` / `.c` 파일에서 하면 됩니다.
Visual Studio 외부 실행 도구나 별도 컴파일러는 사용하지 않습니다.

## 실습 18 조작

| 키 | 동작 |
| --- | --- |
| `p` / `Shift+P` | 직각 투영 / 원근 투영 |
| `m` / `Shift+M` | 솔리드 모델 / 와이어 모델 |
| `w`, `a`, `s`, `d` | 전체 도형을 위, 왼쪽, 아래, 오른쪽으로 이동 |
| `+`, `-` | 전체 도형을 z축 양/음 방향으로 이동 (숫자 키패드도 지원) |
| `1` | 모든 행성과 달 궤도의 반지름을 함께 확대 / 축소 |
| `2` | 중심 구의 크기·색상 애니메이션 시작 / 정지 |
| `3` | 달 궤도의 z축 회전 시작 / 정지 |
| `q` | 종료 |

세 행성의 궤도는 xz 평면 및 이를 z축으로 ±45도 기울인 평면에 있고, 각각 다른 속도로 공전합니다. 달은 각 행성을 따라 이동하면서 화면에 평행한 타원 궤도로 공전합니다. `1`은 궤도 반지름 배율을 1.0배와 1.3배 사이에서 부드럽게 바꿉니다. `2`, `3`을 끄면 중심 구의 크기·색상과 달 궤도의 회전 각도는 현재 상태를 유지합니다.

## 실습 23 조작

| 키 | 동작 |
| --- | --- |
| `o` | 앞벽을 위쪽으로 축소하며 열기 / 닫기 |
| `w`, `a`, `s`, `d` | 로봇의 이동 방향 변경: 앞(-Z), 왼쪽(-X), 뒤(+Z), 오른쪽(+X) |
| `+`, `-` | 걷기 속도와 팔다리의 흔들림 크기·속도 조절 (`=`, 숫자 키패드도 지원) |
| `j` | 평지에서는 제자리 점프, 장애물 가까이에서는 뛰어오르기, 장애물 위에서는 빈 바닥으로 뛰어내리기 |
| `i` | 로봇·점프·속도·앞벽·카메라를 초기 상태로 되돌리기 |
| `z` / `Shift+Z` | 카메라를 앞으로 / 뒤로 이동 |
| `x` / `Shift+X` | 화면을 기준으로 카메라를 왼쪽 / 오른쪽으로 이동 |
| `y` / `Shift+Y` | 현재 화면 중심을 기준으로 양 / 음 방향 공전. 같은 키를 다시 누르면 현재 위치에서 정지 |
| 화살표 위 / 아래 | 카메라를 앞으로 / 뒤로 이동 |
| 화살표 왼쪽 / 오른쪽 | 카메라를 화면의 왼쪽 / 오른쪽으로 이동 |

무대는 가로 5, 높이 3, 깊이 3이며 바닥 중점은 `(0, 0, 0)`입니다. 크기가 다른 장애물 세 개는 실행할 때 서로 겹치지 않는 무작위 위치에 생성됩니다. `i`를 누르면 같은 장애물 배치에서 다시 시작합니다. 무대에는 앞면 컬링, 장애물과 로봇에는 뒷면 컬링을 적용합니다. 앞벽의 윤곽선을 함께 표시해 카메라 쪽 면이 컬링된 상태에서도 개폐 움직임을 확인할 수 있습니다.
